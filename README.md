# Тихий лес · Лесная поляна

[Играть в браузере на GitHub Pages](https://ziridgpt.github.io/quiet-forest-level-1/)

[Открыть сборку с обновлённой панорамой через Githack](https://raw.githack.com/ZiRiDgpt/quiet-forest-level-1/536d5445c20f6c4facfe8d324ae5f6ce9c254f52/docs/index.html)

Первый уровень игры для GDevelop 5.6.284. На двух частях панорамы спрятано десять находок. Семь головоломок имеют размер 10×10, три — 15×15.

1. Откройте `game.json` в GDevelop и запустите предпросмотр со сцены `Forest`.
2. Нажмите на отметку в лесу или на карточку. Перетаскивайте лес мышью или используйте полосу прокрутки, чтобы увидеть правую часть.
3. Решите нонограмму и нажмите «Далее», чтобы увидеть находку на её месте в лесу. Игра сохраняет открытия и текущую попытку локально.

Автоматические проверки запускаются из каталога проекта командой `npm test` (Node.js 20+, без установки зависимостей).

38 автоматических проверок покрывают единственность решения, жизни, сохранения, подсказки и переход от головоломки до появления каждой из десяти находок. Все 12 сцен прошли проверку экземпляров GDevelop.
